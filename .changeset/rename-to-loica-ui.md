The library is now `@loica-ui/react`, and everything that carried the name `plume` carries `loica`: the package and its stylesheets (`@loica-ui/react/styles.css`, `@loica-ui/react/tokens.css`, `@loica-ui/react/css/*`), the `--loica-*` variables, the `data-loica-*` attributes (and `data-loica-color-mode`), the cascade layer `loica`, the `loica-root` class of the `ThemeProvider`, and the types `LoicaMessages` and `LoicaLocale`. Nothing else changes: the components, their props and their look are the same. `plume-ui-react` stays on npm as deprecated and gets no more releases. See _The library is now `@loica-ui/react`_ in the upgrading guide for the list of equivalences.
