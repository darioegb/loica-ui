# Roadmap

What comes next lives in the [issues](https://github.com/darioegb/loica-ui/issues) of the repository, each one in a
milestone. This page says where the library is heading; the milestones say what is in each step and how far along it
is.

## Where it is heading

- **Every component fits the language of the app.** The texts come from the `LocaleProvider`, and since 1.1 the
  numbers, the search and the first day of the week follow the locale too. Next: arrow keys that follow the direction
  of the text in 1.4, and translations that ship with the library.
- **The pieces that apps write by hand today.** Code, keys and links arrived in 1.1, and layout, typography, page
  headers, definition lists, stats and confirmations arrive in 1.2, and a segmented control, a timeline and a command
  palette in 1.3, with the same parts, tokens and `unstyled` as the other components. Next, in 1.4: an autocomplete, a
  color picker, a product tour, submenus and context menus, and resizable panels.
- **A stable API.** Everything above arrives in 1.x minor releases. A change that breaks code, as the
  <a href='./?path=/docs/guides-public-api--docs' target='_top'>Public API</a> page defines it, waits for 2.0.

## Proposing something

[Open an issue](https://github.com/darioegb/loica-ui/issues/new) with what you need and why. If it fits, it goes to
a milestone; if it breaks the API, to 2.0.
