# Roadmap

What comes next lives in the [issues](https://github.com/darioegb/loica-ui/issues) of the repository, each one in a
milestone. This page says where the library is heading; the milestones say what is in each step and how far along it
is.

## Where it is heading

- **Every component fits the language of the app.** The texts already come from the `LocaleProvider`. Next, what the
  components still do by hand: numbers, search that ignores accents, the first day of the week.
- **The pieces that apps write by hand today.** Layout, typography, code and links, with the same parts, tokens and
  `unstyled` as the other components.
- **A stable API.** Everything above arrives in 1.x minor releases. A change that breaks code, as the
  <a href='./?path=/docs/guides-public-api--docs' target='_top'>Public API</a> page defines it, waits for 2.0.

## Proposing something

[Open an issue](https://github.com/darioegb/loica-ui/issues/new) with what you need and why. If it fits, it goes to
a milestone; if it breaks the API, to 2.0.
